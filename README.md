# 쿠짱 키우기 업데이트

공개 APK, 최신 버전 정보 및 새 개발 대화를 위한 인계문을 보관합니다.

## 새 대화에서 개발을 이어갈 때

**[HANDOFF.md — 개발 인계문](HANDOFF.md)을 먼저 읽으세요.** 목표, 현재 기능, 채택된 그림, 미술 규칙, 구현 구조, 검증 상태, 배포 절차와 다음 작업 기준이 정리돼 있습니다.

실제 코드와 원본 그림은 비공개 [koojjang/koojjangbot-app](https://github.com/koojjang/koojjangbot-app)에 있습니다. 이 저장소는 인계 진입점과 배포 용도이며, 코드 수정에는 소스 저장소 접근이 필요합니다. 정확한 배포 저장소 이름은 `koojjang/koojjangbot-app-updates`입니다.

## 현재 배포

현재 공개 버전: **0.1.25 (versionCode 25)**. 이후 최신 버전의 기준은 [latest.json](latest.json)입니다. 최신 CI 실행 번호와 공개 배포 버전은 다를 수 있습니다.

[0.1.25 APK 다운로드](https://raw.githubusercontent.com/koojjang/koojjangbot-app-updates/main/apks/kkyujjang-25.apk)

앱은 실행 시와 설정의 **업데이트 확인** 버튼으로 latest.json을 확인합니다. 새 버전이 있으면 다운로드 안내가 표시됩니다. 다운로드 후 Android 설치 화면에서 직접 설치합니다. 같은 버전에서는 수동 확인 시 최신 버전이라고 표시됩니다.

## 배포 순서

APK를 먼저 업로드하고 확인한 뒤 latest.json을 갱신합니다. APK와 메타데이터 버전은 일치해야 하며 이전 APK는 유지합니다. 문서만 갱신할 때는 APK나 latest.json 버전을 올리지 않습니다. 자세한 절차는 인계문을 참고하세요.
